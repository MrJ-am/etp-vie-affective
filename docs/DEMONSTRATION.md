# Scénario de démonstration

Tous les exemples sont inventés. Camille n’est pas une personne participante. Les comptes de test ont été créés par automatisation ; aucune observation humaine de personnes autistes n’est revendiquée.

1. « Ouvrir la démonstration ». Le carnet s’ouvre directement sur « Mon parcours », avec les trois onglets joints à la feuille sur une seule ligne. Dans « Mon espace », lire « Comprendre le classeur ». Les douze capsules de chapitre partagent la feuille du parcours, avec les bilans avant et après. Appuyer sur l’en-tête d’une capsule, observer le zoom de son contenu préexistant et les capsules suivantes repoussées, puis la refermer à sa place. Dans « Mon espace », ouvrir « Vue d’ensemble » pour consulter la carte des quinze étapes et rejoindre une capsule, ou la fermer pour retrouver le carnet. Lire l’état « Chiffré sur cet appareil » et consulter Avant / Pendant / Entre. Aucun questionnaire obligatoire.
2. Pendant la séance 1 : choisir une carte, préciser son sens, « Placer dans… », indiquer une seconde zone possible. Lire une situation de confrontation, conserver ses choix ou les ajuster, garder une trace. Vérifier Mes repères.
3. Depuis Entre les séances, changer de feuille avec « Mes objectifs » puis revenir par « Mon parcours » : la même capsule et le même moment sont retrouvés, sans déplacement commandé par les onglets. Le bouton « Revenir à la séance » rejoint explicitement le titre de cette capsule après son ouverture. Mes objectifs : ajouter une formulation, la reformuler, consulter les précédentes. Relier un défi, en garder au maximum trois actifs, en mettre un de côté. Préparer un essai, choisir « Pas d’occasion », le retrouver dans la séance suivante.
4. Mes repères : inscrire une étape importante, choisir une trace à présenter localement. Dans « Mon espace », ouvrir « Mes réglages » : mode sobre, texte plus grand, animations arrêtées ; les feuilles et les capsules restent identiques. « Revenir au carnet » retrouve la capsule quittée. Ouvrir la vue d’ensemble puis la fermer par Échap : la carte se retire et le brouillon reste présent. Utiliser les flèches gauche/droite sur un onglet, puis Début/Fin ; descendre dans une capsule longue et retrouver les onglets toujours visibles. Changer de destination pendant un mouvement pour voir son interruption. Réinitialiser les exemples pour un autre essai : le carnet revient directement au parcours.
5. Version complète locale : créer un compte fictif avec deux secrets distincts, télécharger le kit. Écrire une note, attendre « Synchronisé », masquer. Réouvrir avec la phrase. Rafraîchir : le coffre est fermé.
6. Autre navigateur : connexion avec le mot de passe, ouverture avec phrase ou secret du coffre. Retrouver la note. Faire une modification hors connexion, constater la copie locale puis le conflit si l’autre appareil a modifié ; choisir explicitement sa version.
7. Exporter le fichier chiffré, modifier une note puis réimporter avec sa phrase. Constater l’ancien contenu retrouvé. Tester un fichier altéré : refus sans changement. Exporter seulement une sélection lisible après avertissement.
8. Récupérer la connexion avec le code de compte (il ne déchiffre pas). Changer la phrase de coffre ; l’ancienne est refusée pour le coffre actuel. Sans les deux secrets du coffre, créer un nouveau coffre en conservant l’ancien chiffré.
9. Retirer une photo/entrée puis supprimer le compte avec son mot de passe. Vérifier que la connexion et les sessions sont révoquées. Les fichiers téléchargés ne sont pas effacés à distance.

Les captures de `captures/` montrent la démo. Les tests et résultats sont détaillés dans `RESULTATS.md` ; l’API est réelle et les captures de référence n’utilisent aucun patient ni secret.
